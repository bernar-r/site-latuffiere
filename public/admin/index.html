📖 Mode d'emploi — Comment modifier votre site ?

Bonjour Bénédicte & Christian ! Vous êtes directement sur votre site internet en mode écriture.

1

Choisissez la page en haut

Cliquez sur 🍽️ Table d'hôtes pour vos plats et menus, 💶 Grille des Tarifs pour vos prix, ou ❓ FAQ pour les questions pratiques.

2

Cliquez directement sur un texte ou un prix

Chaque élément modifiable s'entoure d'un cadre vert lorsque vous cliquez dessus. Tapez simplement vos nouveaux plats ou tarifs au clavier comme dans un document texte.

3

Ajoutez ou supprimez facilement

Utilisez les boutons « + Ajouter un plat » sous les entrées, plats ou desserts, ou cliquez sur la petite corbeille 🗑️ à droite d'un plat pour l'effacer.

4

Cliquez sur « 💾 Enregistrer & Publier »

Dès que vous avez terminé, cliquez sur le bouton orange « Enregistrer & Publier » en haut à droite. Vos modifications seront visibles pour tous vos clients sur internet en 1 à 2 minutes !

🔑 Clé d'accès GitHub (Publication)

Cette clé permet d'enregistrer directement vos modifications sur le site hébergé sur GitHub. Elle est conservée sur votre ordinateur.
