📖 Comment modifier votre site ?

C'est très simple, vous êtes directement sur votre site en mode écriture :

1

Choisissez la page en haut

Cliquez sur 🍽️ Table d'hôtes pour les plats, 💶 Grille des Tarifs pour les prix, ou ❓ Questions Fréquentes pour la FAQ.

2

Cliquez directement sur un plat ou un prix

Le texte s'entoure d'un cadre vert. Tapez simplement vos modifications au clavier, exactement comme dans Word.

3

Ajoutez ou supprimez des plats

Cliquez sur les boutons « ➕ Ajouter un plat » sous les entrées, plats ou desserts, ou sur la corbeille 🗑️ pour effacer un plat.

4

Cliquez sur « 💾 Enregistrer » en haut à droite

La fenêtre vous demande votre clé d'accès la première fois, puis vos modifications sont publiées en ligne automatiquement !
